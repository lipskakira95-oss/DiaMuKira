# Навчальні матеріали «Дія Ми»

[questions.uk.csv](questions.uk.csv) містить **152 авторські чернетки**: 21 для дітей, 27 для учнів, 33 для вчителів, 39 для батьків і 32 для медіа. Записи впорядковані за категорією, раундом і позицією.

Це запропоновані нові запитання про повагу й доступність. Повного оригінального набору не надано, тому файл не можна представляти як перенесення запитань із вихідного документа. Перед навчальним випуском потрібна перевірка педагогом/редактором, зокрема відповідності віку, точності відповідей, формулювань і пояснень.

| Поле | Значення |
| --- | --- |
| `category_id`, `category_name` | Стабільний код і українська назва аудиторії. |
| `round_number`, `round_title`, `position` | Номер і тема раунду, місце запитання. |
| `question_id` | Унікальний ID; не змінювати під час перестановки. |
| `question`, `answer`, `explanation` | Запитання, рівно «Так» або «Ні», пояснення. |
| `status` | `draft` до перевірки; `approved` після реального затвердження. |
| `source` | Початково `author_draft`; після редакторської роботи можна вказати підставу. |
| `content_version` | Одна версія для всього набору; змінювати при змінах. |

Формат: UTF-8 BOM, кома, стандартне CSV-екранування. Якщо Excel не розділяє колонки, використати імпорт тексту із роздільником «кома», не змінювати формат мовчки. Імпортер відхиляє порожні відповіді, дублікати ID/позицій, незнайомі категорії й некоректні раунди.

Go створює SQLite-файл локально. CSV і SQL-схема зберігаються в Git, сама БД і резервні копії — ні. Для production усі записи мають бути затверджені, а кількості — точно відповідати 18 раундам.
