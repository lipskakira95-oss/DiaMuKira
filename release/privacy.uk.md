# Чернетка інформації про конфіденційність

## Які дані використовує застосунок

| Дані | Де зберігаються | Передавання |
| --- | --- | --- |
| Відповіді та результати раундів | Локальна SQLite-база користувача | Не передаються поточним API. |
| Налаштування | Локальна SQLite-база користувача | Не передаються. |
| Навчальний каталог | Вбудований файл, локальний кеш або Go API | API передає лише матеріали до застосунку. |

Поточна реалізація не має реєстрації, рекламного SDK, аналітики, геолокації, контактів, камери чи завантаження результатів на сервер. Очищення даних застосунку або видалення застосунку видаляє локальний прогрес.

Перед публікацією власник продукту має додати назву й контакти відповідальної організації, адресу повної політики конфіденційності, строк зберігання серверних журналів і опис інфраструктури production API. Якщо пізніше буде додано аналітику або облікові записи, декларації магазинів потрібно оновити до випуску такої версії.
