# iPhone-застосунок

## Підтримувана платформа

| Параметр | Значення |
| --- | --- |
| Платформа | iPhone |
| Мінімальна версія | iOS 15.0 |
| Bundle ID | `ua.diiamy.diiaMy` |
| Назва | `Дія Ми` |
| Локальна база | Drift поверх SQLite |
| Орієнтація | портретна |
| API | HTTPS через `--dart-define=API_BASE_URL=https://example.org` |

Початковий набір запитань входить у застосунок. Тому вікторину можна вперше відкрити без мережі. Прогрес і налаштування зберігаються у SQLite на iPhone.

## Збірка на Mac

Для iOS потрібні macOS, Xcode та Flutter 3.50.0. З кореня репозиторію виконайте:

```bash
./scripts/build-ios.sh debug
```

Скрипт створює непідписаний застосунок для iPhone Simulator. Для release-збірки без підпису виконайте:

```bash
./scripts/build-ios.sh release https://example.org
```

Непідписаний `.xcarchive` для технічної перевірки створює `scripts/archive-ios.sh`. Підпис і export для App Store потребують Apple Developer Team, distribution certificate та provisioning profile. Секрети Apple не зберігаються в Git; повний порядок наведено в [інструкції випуску](release.md).

## Автоматичні перевірки

GitHub Actions на macOS виконує аналіз, unit/widget-тести, збірку для iPhone Simulator та інтеграційний smoke-тест:

```bash
./scripts/smoke-ios.sh [simulator-udid]
```

Smoke-тест проходить один раунд із вбудованими даними, закриває локальну базу, відкриває її повторно і перевіряє збережений прогрес.

## Перевірка на справжньому iPhone

Перед випуском вручну перевіряють:

1. запуск і повторний запуск без мережі;
2. збереження прогресу та чотирьох налаштувань;
3. звук у звичайному і беззвучному режимах;
4. тактильний відгук для неправильної відповіді;
5. читання екранів за допомогою VoiceOver;
6. довгі тексти та збільшений системний шрифт.

Симулятор підтверджує навігацію і SQLite, але не замінює перевірку реального звуку та вібрації на фізичному iPhone.
