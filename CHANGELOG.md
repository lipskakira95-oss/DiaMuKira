# Журнал змін

## 1.0.0-preview.1 — 22 листопада 2026

Перший перевірений preview-кандидат «Дія Ми» для вебу, Android та iPhone.

### Додано

- 5 категорій користувачів, 18 раундів і 152 авторські позиції зі статусом `draft`;
- Go API та SQLite-каталог із перевіркою структури й production guard;
- спільний Flutter-застосунок для вебу, Android та iPhone;
- локальний прогрес, налаштування і кеш у Drift/SQLite;
- офлайн-режим, прямі вебпосилання та адаптивний інтерфейс;
- семантичні заголовки, клавіатурну навігацію й перевірку контрасту;
- автоматичні Go, Flutter, Chrome, Edge, Android та iPhone Simulator перевірки;
- unsigned AAB, unsigned iPhone archive і автономний web preview як CI-артефакти.

### Відомі обмеження

- матеріали ще не затверджені педагогом або редактором і не є production-вмістом;
- preview-пакети не підписані ключами Google Play та Apple Developer;
- Firefox, Safari і фізичні Android/iPhone потребують остаточного ручного приймання;
- публічну HTTPS-адресу production API ще не надано.
