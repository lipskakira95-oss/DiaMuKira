# Якість і доступність

## Автоматичні критерії

| Перевірка | Що підтверджує |
| --- | --- |
| 152 позиції | ID `q001`–`q152`, п’ять категорій, 18 раундів і запланований розподіл. |
| Повне проходження | Кожен із 18 раундів можна завершити правильними відповідями; прогрес стає безпомилковим. |
| Production guard | Поточні `draft`-матеріали не можна імпортувати або видати як production. |
| Семантика | Прогрес має назву і числове значення, запитання позначене заголовком, результат озвучується як live region. |
| Клавіатура | Основний сценарій можна почати клавішами Tab і Enter. |
| Контраст | Основні пари кольорів відповідають WCAG AA 4.5:1 для звичайного тексту. |
| Масштабування | Немає переповнення на 390×844, 768×1024, 1440×900; окремо перевіряється 360×800 із текстом 200%. |
| Помилка сховища | Збій запису не показує неправдиве повідомлення про збережений прогрес. |
| Web smoke | Chrome та Edge: URL, 7/7, SQLite після reload, offline reload, пряме й некоректне посилання. |
| Мобільні CI | Android APK та iPhone Simulator збираються у своїх workflow; iPhone Simulator проходить SQLite smoke. |

## Вебмаршрути

| URL | Результат |
| --- | --- |
| `/` | Початковий екран. |
| `/categories` | Список категорій. |
| `/categories/{category}/rounds` | Раунди вибраної категорії. |
| `/rounds/{category}-{number}` | Початок конкретного раунду. Наприклад, `/rounds/children-1`. |
| `/settings` | Налаштування. |
| Невідомий URL або ID | Екран «Посилання недійсне» з кнопкою повернення до категорій. |

Go web host повертає `index.html` для маршрутів інтерфейсу, але не підміняє ним помилки `/api/` або відсутні файли. Flutter читає шлях після завантаження перевіреного каталогу й відновлює потрібний екран.

## Фактична матриця

| Платформа | Автоматично | Ще потрібно вручну |
| --- | --- | --- |
| Chrome | Повний web smoke, offline і deep links. | Читання реальним screen reader за потреби. |
| Edge | Повний web smoke, offline і deep links. | Читання реальним screen reader за потреби. |
| Firefox | Unit/стандарти Flutter, але браузерний smoke не запускався. | Основний сценарій, offline, клавіатура. |
| Safari | iOS Simulator build не дорівнює Safari web. | Основний сценарій, offline, клавіатура на macOS. |
| Android | APK build і спільні тести. | Фізичний offline/restart, звук, вібрація, TalkBack. |
| iPhone | Simulator build та SQLite smoke. | Фізичний offline/restart, sound/silent mode, haptics, VoiceOver. |

Firefox не встановлений у поточному Windows-середовищі, а Safari доступний лише на macOS. Ці рядки мають статус `NOT RUN`, доки тест не буде фактично виконано.

## Стан навчального вмісту

Структурно набір повний: 152 позиції у 18 раундах. Усі записи є авторськими чернетками `draft`. Вони ще не підтверджені педагогом або редактором. Production-імпорт навмисно завершується помилкою на `q001`; змінювати статуси лише для проходження тесту заборонено.

Перед production-випуском редактор має перевірити вікову відповідність, фактичну точність, відповіді, пояснення й формулювання кожної позиції. Після реального затвердження потрібно змінити статуси, джерело та версію вмісту, повторити production validation і всю матрицю.
